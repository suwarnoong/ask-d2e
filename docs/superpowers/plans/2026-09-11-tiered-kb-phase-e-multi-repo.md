# Tiered KB Phase E — Multi-repo depth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each snapshot generated (tier-3) knowledge of the three repos that make up a D2E install — Data2Evidence itself, Atlas3 and trex — plus one version-independent WebAPI contract tier, so questions whose answer crosses a repo boundary can be answered from mutually consistent refs.

**Architecture:** Phase D made the version axis real for tiers 1–2 and records each snapshot's pins in `snapshots.json`. Phase E puts tier-3 content under those pins: `snapshots/<id>/generated/<repo>/**.md`, generated by the existing Claude-Code pipeline (`initialBuild.ts`), which explores a real checkout and writes a bounded knowledge base. The WebAPI material is different in kind — Data2Evidence does not ship it — so it is built once into `repos/_shared/webapi-contract/**` and always labelled a contract specification.

**Tech Stack:** Node >=20, TypeScript ^5.5, ESM (`"type": "module"`, NodeNext), `tsx`, Node's built-in `node:test` / `node:assert/strict`. No new runtime or test dependencies.

**Spec:** `docs/superpowers/specs/2026-09-11-multi-repo-tiered-kb-design.md` (phases E and F; risk #1)
**Predecessors:** phases A–C (shipped), phase D (`docs/superpowers/plans/2026-09-11-tiered-kb-phase-d-snapshots.md`, shipped 2026-09-11)

How the existing tier-3 pipeline works (read before starting):

- `src/kb/initialBuild.ts` → `runInitialBuild(config, deps)`: builds a prompt from a source checkout
  (`listSourceFiles`, `readReadmes`, `buildInitialBuildPrompt`), spawns the Claude Code CLI with
  `allowedTools: ["Read", "Grep", "Glob"]`, parses JSON out of the reply with `parseKbResponse`,
  writes with `applyKbChanges`, then registers in `repos.json` and pushes. `deps` is injectable —
  that seam is what makes this testable without credentials.
- `buildInitialBuildPrompt` **hardcodes** the output prefix `repos/<name>/knowledge-base/`.
- `applyKbChanges`/`safeRepoKbPath` **refuse** to write anywhere outside `repos/<name>/knowledge-base/`.
- `src/shared/claude.ts#callClaude(prompt, auth, { cwd, allowedTools, spawnCmd })` is the only
  model entry point; it requires `CLAUDE_CODE_OAUTH_TOKEN`.

**Constraint to plan around:** this working environment has no `CLAUDE_CODE_OAUTH_TOKEN`, so the
real generation run is a CI/manual step (GitHub Actions `kb-initial-build.yml` is the existing
pattern). Every task below is built and tested with an injected `callClaude`; only task 5's last
step invokes the real thing, and it must be run where the token lives.

## Scope boundary

In scope: the write paths, the generation core, per-snapshot orchestration, the shared WebAPI tier,
the bounded prompt specs for Atlas3/trex/WebAPI, and manifest rebuilding so generated files are
discoverable by the retrieval tools. Out of scope: scheduled refresh and new-release detection
(phase F — note `kb-refresh.yml` is already merged and refreshes `repos/*/knowledge-base`, not
snapshots), and the public web surface (phase G).

## Global Constraints

- Node >=20, TypeScript ^5.5, ESM (`"type": "module"`), NodeNext resolution; intra-repo imports use
  the `.js`-suffix-on-`.ts`-source convention.
- **No new dependencies.** Tests use `node:test` / `node:assert/strict` via `tsx --test`.
- **Tier-3 content is written only under `snapshots/<id>/generated/<repo>/` or
  `repos/_shared/webapi-contract/`**, never anywhere else, and never under `curated/`.
- **Fail loudly, write nothing partial.** All clones and all generations happen before any write;
  a failure at any point leaves the KB repo exactly as it was.
- **WebAPI is always described as a contract specification**, never as install behaviour.
- Generated knowledge bases are **bounded by their prompt spec** (`focusAreas`, `scopeNotes`) — the
  spec's risk #1 is unbounded initial builds.
- Files stay focused: 200–400 lines typical, 800 hard maximum. Functions under 50 lines.
- No mutation of inputs.
- All paths crossing a trust boundary are validated before any filesystem access.

```typescript
import { mkdirSync, writeFileSync } from "node:fs";
import { resolve, sep } from "node:path";
import type { KbChange } from "./responseParsing.js";

function assertMarkdown(relPath: string): void {
  if (!relPath.endsWith(".md")) {
    throw new Error(`Refusing to write a non-markdown file: "${relPath}"`);
  }
}

/** The write guard for `snapshots/<id>/generated/<repo>/`. Mirrors safeRepoKbPath's discipline. */
export function safeSnapshotGeneratedPath(
  kbRoot: string,
  snapshotId: string,
  repoName: string,
  relPath: string,
): string {
  const targetRoot = resolve(kbRoot, "snapshots", snapshotId, "generated", repoName);
  const target = resolve(kbRoot, relPath);
  if (target === targetRoot || !target.startsWith(targetRoot + sep)) {
    throw new Error(
      `Refusing to write outside snapshots/${snapshotId}/generated/${repoName}/: "${relPath}"`,
    );
  }
  assertMarkdown(relPath);
  return target;
}

export function applySnapshotKbChanges(
  changes: KbChange[],
  kbRoot: string,
  snapshotId: string,
  repoName: string,
): string[] {
  const targets = changes.map((change) => ({
    change,
    absPath: safeSnapshotGeneratedPath(kbRoot, snapshotId, repoName, change.path),
  }));
  for (const { absPath } of targets) mkdirSync(resolve(absPath, ".."), { recursive: true });
  for (const { change, absPath } of targets) {
    writeFileSync(absPath, change.content.endsWith("\n") ? change.content : `${change.content}\n`);
  }
  return targets.map((t) => t.change.path);
}

/** The shared, version-independent WebAPI contract tier. */
export function safeSharedContractPath(kbRoot: string, relPath: string): string {
  const targetRoot = resolve(kbRoot, "repos", "_shared", "webapi-contract");
  const target = resolve(kbRoot, relPath);
  if (target === targetRoot || !target.startsWith(targetRoot + sep)) {
    throw new Error(`Refusing to write outside repos/_shared/webapi-contract/: "${relPath}"`);
  }
  assertMarkdown(relPath);
  return target;
}

export function applySharedContractChanges(changes: KbChange[], kbRoot: string): string[] {
  const targets = changes.map((change) => ({
    change,
    absPath: safeSharedContractPath(kbRoot, change.path),
  }));
  for (const { absPath } of targets) mkdirSync(resolve(absPath, ".."), { recursive: true });
  for (const { change, absPath } of targets) {
    writeFileSync(absPath, change.content.endsWith("\n") ? change.content : `${change.content}\n`);
  }
  return targets.map((t) => t.change.path);
}
```

```typescript
import { readFileSync, readdirSync, statSync, writeFileSync } from "node:fs";
import { join, relative, sep } from "node:path";
import type { KbFile } from "./kbFiles.js";
import { buildManifest, extractTitle, type KbManifest } from "./manifest.js";
import { summariseDoc } from "./buildDocsTier.js";

function walkMarkdown(dir: string, out: string[]): void {
  let entries: string[];
  try {
    entries = readdirSync(dir);
  } catch {
    return;
  }
  for (const entry of entries) {
    const full = join(dir, entry);
    let stat;
    try {
      stat = statSync(full);
    } catch {
      continue;
    }
    if (stat.isDirectory()) walkMarkdown(full, out);
    else if (entry.endsWith(".md")) out.push(full);
  }
}

/** Every markdown file a snapshot holds, as repo-relative paths. */
export function collectSnapshotFiles(kbRoot: string, snapshotId: string): KbFile[] {
  const snapshotDir = join(kbRoot, "snapshots", snapshotId);
  const absolute: string[] = [];
  walkMarkdown(join(snapshotDir, "docs"), absolute);
  walkMarkdown(join(snapshotDir, "generated"), absolute);

  const troubleshooting = join(snapshotDir, "troubleshooting.md");
  try {
    readFileSync(troubleshooting);
    absolute.push(troubleshooting);
  } catch {
    // No troubleshooting index — a snapshot without one is still indexable.
  }

  return absolute
    .sort()
    .map((abs) => ({
      path: relative(kbRoot, abs).split(sep).join("/"),
      content: readFileSync(abs, "utf8"),
    }));
}

export function rebuildSnapshotManifest(kbRoot: string, snapshotId: string): KbManifest {
  const files = collectSnapshotFiles(kbRoot, snapshotId);
  const manifest = buildManifest(snapshotId, files, (file) =>
    summariseDoc({
      outPath: file.path,
      sourcePath: file.path,
      title: extractTitle(file.content),
      content: file.content,
    }),
  );
  writeFileSync(
    join(kbRoot, "snapshots", snapshotId, "manifest.json"),
    `${JSON.stringify(manifest, null, 2)}\n`,
  );
  return manifest;
}
```

  - `function buildRepoPrompt(options: GenerateRepoKbOptions): string`

**Context:** `runInitialBuild` couples prompt-building, model call, parsing, writing, registry
updates and pushing in one function. E needs the first three only, parameterised by target, so the
orchestrator can generate several repos and write nothing until all of them succeed. Splitting it
here keeps `initialBuild.ts` untouched for the single-repo flow.

`buildInitialBuildPrompt` gains an optional target: existing callers keep today's
`repos/<name>/knowledge-base/` prefix and see no behaviour change.

partially-built snapshot. If any repo's clone or generation fails, nothing has been written yet and
the KB repo is untouched. The manifest is rebuilt once, after all writes.

```typescript
import { execFileSync } from "node:child_process";
import { mkdirSync } from "node:fs";

export interface CloneRequest {
  /** `owner/name`, or a local path in tests. */
  repo: string;
  /** Branch, tag or commit SHA. */
  ref: string;
  dir: string;
}

export type Cloner = (request: CloneRequest) => void;

function git(dir: string, args: string[]): string {
  return execFileSync("git", args, { cwd: dir, encoding: "utf8", stdio: ["ignore", "pipe", "pipe"] });
}

/**
 * Fetches exactly one ref and checks it out. Works for tags and bare commit SHAs alike, which a
 * `git clone --branch` cannot do — Atlas3 and trex are pinned by commit. A missing ref throws
 * here, before the caller has written anything.
 */
export function cloneAtRef(request: CloneRequest, token: string): void {
  const url = request.repo.includes("/") && !request.repo.startsWith("/")
    ? `https://x-access-token:${token}@github.com/${request.repo}.git`
    : request.repo;

  mkdirSync(request.dir, { recursive: true });
  git(request.dir, ["init", "-q"]);
  git(request.dir, ["remote", "add", "origin", url]);
  git(request.dir, ["fetch", "--depth", "1", "origin", request.ref]);
  git(request.dir, ["checkout", "-q", "FETCH_HEAD"]);
}
```

```typescript
import { join } from "node:path";
import { generateRepoKb, type ClaudeCaller } from "./generateRepoKb.js";
import { cloneAtRef, type Cloner } from "./snapshotSources.js";
import { applySnapshotKbChanges } from "./snapshotKbFiles.js";
import { rebuildSnapshotManifest } from "./snapshotManifest.js";
import { REPO_PROMPT_SPECS, GENERATED_REPOS } from "./repoPromptSpecs.js";
import type { ClaudeAuth } from "../shared/config.js";
import type { KbPlan } from "./responseParsing.js";

export interface BuildSnapshotKbInput {
  kbRoot: string;
  snapshotId: string;
  refs: { d2e: string; atlas3: string; trex: string };
  auth: ClaudeAuth;
  /** Parent directory for the per-repo checkouts. */
  workRoot: string;
  deps?: { clone?: Cloner; callClaude?: ClaudeCaller };
}

export interface BuildSnapshotKbResult {
  repos: { repoName: string; files: number }[];
  manifestEntries: number;
}

/**
 * Generate the tier-3 KB for every repo of one snapshot. Collect first — all clones and all model
 * calls — and only then write, so a failure cannot leave a half-built snapshot behind.
 */
export async function buildSnapshotKb(input: BuildSnapshotKbInput): Promise<BuildSnapshotKbResult> {
  const clone = input.deps?.clone ?? ((request) => cloneAtRef(request, process.env.SOURCE_REPOS_TOKEN ?? ""));

  const collected = [];
  for (const repo of GENERATED_REPOS) {
    const dir = join(input.workRoot, `${input.snapshotId}-${repo.name}`);
    clone({ repo: repo.sourceRepo, ref: input.refs[repo.name], dir });
    const plan: KbPlan = await generateRepoKb({
      sourceDir: dir,
      repoName: repo.name,
      sourceRepo: repo.sourceRepo,
      promptSpec: REPO_PROMPT_SPECS[repo.name],
      target: { pathPrefix: `snapshots/${input.snapshotId}/generated/${repo.name}/` },
      auth: input.auth,
      callClaude: input.deps?.callClaude,
    });
    collected.push({ repo, plan });
  }

  const repos = collected.map(({ repo, plan }) => ({
    repoName: repo.name,
    files: applySnapshotKbChanges(plan.changes, input.kbRoot, input.snapshotId, repo.name).length,
  }));
  const manifest = rebuildSnapshotManifest(input.kbRoot, input.snapshotId);

  return { repos, manifestEntries: manifest.entries.length };
}
```

```typescript
        "Describe it as a contract, never as the behaviour of a running Data2Evidence install.",
    },
    auth: input.auth,
    callClaude: input.deps?.callClaude,
  });

  const paths = applySharedContractChanges(plan.changes, input.kbRoot);
  return { files: paths.length, paths };
}
```
